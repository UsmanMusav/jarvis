# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Нумерация версий — [семантическая](https://semver.org/lang/ru/).

## [1.1.0] — 2026-10-12

### Добавлено
- **Установщики для всех систем**: `Setup.exe` для Windows (Inno Setup, без прав
  администратора), `.dmg` для macOS, `.tar.gz` + `install.sh` для Linux.
- **Автообновление через GitHub Releases**: баннер в окне, кнопка «Обновить»,
  проверка SHA256, тихая установка, голосовая команда «Джарвис, проверь обновления».
- **GitHub Actions**: `tests.yml` гоняет тесты на трёх ОС и двух версиях Python,
  `release.yml` по тегу `v*` собирает и публикует релиз.
- **Иконка приложения** в форматах `.ico`, `.icns` и наборе PNG.
- Голосовая библиотека расширена с 10 до 25 клипов: добавлены `welcome`, `busy`,
  `confirm`, `error`, `standby`, `update`, `updated`.
- Команды «какая у тебя версия» и «проверь обновления».
- Флаги `--version` и `--update` в командной строке.
- Инструменты `tools/split_clips.py` и `tools/polish_clips.py` для работы с озвучкой.
- 23 новых теста автообновления (всего 82).

### Изменено
- Голоса перезаписаны: подобраны ближе к киношной манере — спокойный британский
  тон для английского, низкий «дворецкий» регистр для русского.
- Настройки и заметки у собранной версии теперь хранятся в стандартной папке
  данных ОС, а не рядом с программой (Program Files недоступен для записи).
- Окно настроек получило прокрутку, кнопки сохранения закреплены внизу.

### Исправлено
- Выбор файла обновления больше не путает платформы: подстрока «win» находилась
  внутри слова «darwin», из-за чего на macOS качался архив для Windows.
- Учитывается архитектура процессора — на x86 больше не предлагается ARM-сборка.
- Клипы получили затухание по краям, пропали щелчки при воспроизведении.

## [1.0.0] — 2026-10-12

### Добавлено
- Первая версия: распознавание речи, голосовые ответы, 40+ команд управления
  компьютером, ответы на вопросы без интернета, интерфейс HUD на tkinter,
  поддержка Windows, macOS и Linux, русский и английский языки.
